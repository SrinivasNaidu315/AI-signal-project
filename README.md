# Crack One MERN project

## Overview
Crack One is a MERN stack web application that helps students explore, compare and search colleges easily.

## Features
- Dynamic college listing
- Search colleges
- Compare colleges
- College details page
- Login and Register UI
- MongoDB database integration
- Responsive design using Tailwind CSS

## Tech Stack
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas

## Setup Instructions

### Frontend
```bash
cd college-client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```
